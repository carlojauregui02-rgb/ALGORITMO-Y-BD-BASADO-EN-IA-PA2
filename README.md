## 2. Descripción y objetivo

**Problema:**

Una organización necesita gestionar solicitudes de servicio que se registran, consultan, modifican y eliminan conforme se atienden. Para representar esta información de manera dinámica, se propone utilizar listas enlazadas, que permiten incorporar y retirar nodos sin depender de un tamaño fijo previamente establecido.

**Objetivo:**

Aplicar los conceptos de listas enlazadas para organizar y gestionar solicitudes de servicio, implementando operaciones de inserción, búsqueda, modificación, eliminación y recorrido de nodos, así como reconociendo las características de las listas simplemente enlazadas, doblemente enlazadas y circulares.

**Solución desarrollada:**

Se desarrolla una solución basada en estructuras dinámicas para representar las solicitudes mediante nodos enlazados. Se implementan las operaciones correspondientes a cada actividad y se realizan pruebas para verificar su funcionamiento. Asimismo, se analizan los tipos de listas enlazadas y sus características, considerando su utilidad para organizar y administrar información.

## 3. Cómo ejecutar o revisar

### Requisitos previos

- Apache NetBeans.
- JDK compatible con la configuración del proyecto.
- Git, si se desea clonar el repositorio desde la terminal.

### Pasos para revisar el proyecto

1. **Clonar el repositorio:** ejecutar el siguiente comando en CMD desde la carpeta donde se desea guardar el proyecto.

   ```bash
   git clone https://github.com/carlojauregui02-rgb/ALGORITMO-Y-BD-BASADO-EN-IA-PA2.git
   ```

2. **Abrir el proyecto:** iniciar Apache NetBeans, seleccionar `File > Open Project` y elegir la carpeta descargada.

3. **Revisar el código:** comprobar los archivos Java correspondientes a las cuatro actividades y la documentación complementaria.

4. **Ejecutar las actividades:** abrir la clase de prueba correspondiente a cada actividad y ejecutarla para comprobar los resultados en la consola.

5. **Verificar los resultados:** revisar que las operaciones implementadas funcionen de acuerdo con los requisitos de cada actividad.

## 7. Conclusiones


**Conclusión 1:** Con este trabajo comprendimos cómo funcionan las listas enlazadas y cómo se representan mediante nodos conectados entre sí. También aprendimos a reconocer las diferencias entre las listas simplemente enlazadas, doblemente enlazadas y circulares.

**Conclusión 2:** Al trabajar con el recorrido y la inserción, comprendimos cómo recorrer los nodos de una lista enlazada y agregar nuevas solicitudes. Esto nos permitió entender cómo se organiza dinámicamente la información.

**Conclusión 3:** Al implementar la búsqueda y modificación, aprendimos a localizar solicitudes mediante su código y actualizar sus datos. Esto nos permitió comprender la importancia de acceder a la información de manera precisa.

**Conclusión 4:** Al desarrollar la eliminación de nodos, comprendimos cómo retirar una solicitud y actualizar los enlaces para mantener la continuidad de la lista. También reconocimos la importancia de considerar la posición del nodo que se desea eliminar.

**Conclusión 5:** Al desarrollar la solución de gestión de solicitudes, comprendimos cómo aplicar las estructuras de datos dinámicas para organizar información y realizar operaciones de manera ordenada. Asimismo, reforzamos nuestros conocimientos de programación y la importancia del trabajo en equipo.
