# ACTIVIDAD 1: LISTAS ENLAZADAS

## Introducción
En esta actividad se estudian las listas enlazadas, una estructura de datos que permite organizar y almacenar información mediante nodos conectados entre sí. Cada nodo contiene información y uno o varios enlaces que permiten recorrer la lista.

## ¿Qué es una lista enlazada?
Una lista enlazada está formada por nodos, donde cada uno almacena un dato y una referencia que permite llegar al siguiente nodo. A diferencia de los arreglos, los elementos no necesitan estar almacenados en posiciones consecutivas de memoria.

## Clasificación de las listas enlazadas
- **Lista simplemente enlazada:** cada nodo apunta al siguiente nodo y el último termina en `NULL`.
- **Lista doblemente enlazada:** cada nodo tiene un enlace al nodo anterior y otro al siguiente.
- **Lista circular:** el último nodo se conecta nuevamente con el primero, formando un ciclo.

## Representación gráfica
Una lista simplemente enlazada se puede representar de la siguiente manera:

`[Nodo 1] → [Nodo 2] → [Nodo 3] → NULL`

Esta representación muestra cómo se conectan los nodos y cómo se indica el final de la lista.

## Importancia de las listas enlazadas
Las listas enlazadas permiten organizar información de manera flexible. Son útiles para agregar, buscar y eliminar elementos según las necesidades de un programa o sistema.

## Conclusión
Con esta actividad se comprende cómo funcionan las listas enlazadas, cómo se clasifican y cómo se representan mediante nodos. Este conocimiento ayuda a desarrollar una mejor comprensión de las estructuras de datos y su aplicación en la programación.
